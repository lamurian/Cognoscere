## Summary

Several open-source projects implement pieces of ResearchRabbit's functionality and can be studied or forked. Inciteful is the closest reference implementation: open-source bibliographic-coupling recommendations over open scholarly data. Citation Gecko is an earlier citation-graph explorer worth reading for its interaction model.

The OpenCitations infrastructure itself is open — its REST API is built with RAMOSE, an ISC-licensed API manager over SPARQL endpoints, with a public GitHub issue tracker. Semantic Scholar also publishes code and datasets, and ResearchGraph provides related tooling.

If the real need is just keeping a reading list current, a Zotero plugin with Better BibTeX is far less work than a full clone. Litmaps, Connected Papers, and scite are closed-source competitors whose sites offer no reusable code or open data [@unknown2025b] [@unknown2025e].

## Key Points

- Inciteful: open-source bibliographic-coupling recommendations; best starting point.
- Citation Gecko: earlier citation-graph explorer.
- OpenCitations (RAMOSE, ISC-licensed), Semantic Scholar code/datasets, ResearchGraph.
- Litmaps, Connected Papers, scite: closed-source, no reusable code.
- Zotero + Better BibTeX is a lighter alternative if only a live reading list is needed.
