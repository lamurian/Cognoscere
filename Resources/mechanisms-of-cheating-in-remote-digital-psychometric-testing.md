## Summary

Cheating in remote digital psychometric testing takes multiple forms, each with differential impact on measurement integrity. Scherrer et al. (2025) distinguish cheatability by task type rather than simple searchability. Reasoning tasks (e.g., figural matrices) have low cheatability because they require complex inductive reasoning that cannot easily be conveyed or searched. Memory tasks have high cheatability through note-taking or screen photography. Processing speed tasks are essentially uncheatable because any external aid incurs time costs. Divergent thinking tasks have moderate cheatability, potentially solvable via AI [@scherrer2025].

The most significant emerging threat is large language model (LLM) cheating. Hickman's research at Virginia Tech found that OpenAI's o1 reasoning model renders unproctored assessments of verbal ability, situational judgement, and personality tests essentially worthless — the model can solve them by simple copy-paste [@izlar2025]. Few, if any, unproctored tests remain safe from LLM-based cheating, and approximately one-third of applicants already use these models on high-stakes tests [@izlar2025].

Sanz et al. (2020) studied statistical detection of cheating in unproctored Internet tests (UITs) using verification tests (VTs). They compared five statistics for detecting cheating in Computerized Adaptive Tests and found the Modified Signed Likelihood Ratio Test (MSLRT) had the highest power with appropriate Type I error rates [@sanz2020]. Their simulation approach modelled honest candidates responding to both UIT and VT at their true ability level, while cheaters only performed well on the VT.

Elosua (2021) categorises threats to remote test validity across four domains: technology (access, security), personal/situational (ICT competence, environment), test (changed administration conditions, copyright), and process (confidentiality). The presence of distracting elements or external aids in uncontrolled environments is a primary concern [@elosua2020].

## Key Points

- Cheatability varies by task type: memory > divergent thinking > reasoning > processing speed
- LLMs now make unproctored verbal, personality, and situational judgement tests vulnerable
- Statistical cheating detection (MSLRT) offers post-hoc identification but requires verification test designs
- Environmental control loss is a fundamental threat unique to remote administration
